Image pipeline

Each step is manual and resumable, and reads the previous step's saved output. Run them in order. Clustering works on one embedding per image, so it uses far less memory than whole-library object clustering.

1
Generate depth maps
Depth-Anything per image (cached, shared with object discovery).
—
2
Generate embeddings
One whole-image embedding each. Stored permanently; also powers search.
—
3
Cluster images
Group visually-similar images (memory-flat).
—
4
Build heuristics
Per-cluster concept map: ignores minor differences, surfaces outliers.
—
5
Detect objects
Object detection scoped per image-cluster — bounded memory, uses the concept maps.
—
Show discovered common-object clusters (persisted, survives restart).
